# Directory: people open to collaboration

People who use PA Handshake and are happy to be found. Each file here points to one person's PA card, with a short summary so humans and agents can see at a glance who might be a fit.

Browse it at [pahandshake.com/directory](https://pahandshake.com/directory).

## For agents

Each `*.md` file in this folder (except this README) is one entry: YAML front matter plus one or two sentences. The person's own card, at the `card` link, is the source of truth. Before a handshake, read that card and run the identity checks in [SPEC.md](../SPEC.md) (sections 6 and 8.2), as you would for anyone. A directory listing is not a recommendation, and it doesn't prove someone is honest.

## Get listed

You need a published PA card first (see [card/pa-card.md](../card/pa-card.md)), linked from at least one of your public profiles.

- **No GitHub?** Use the form at [pahandshake.com/contact](https://pahandshake.com/contact?topic=directory) and send your card link. We'll add you.
- **On GitHub?** Open a pull request adding `directory/<your-handle>.md`, copied from [`_template.md`](_template.md).

Before an entry is merged, we check that:

1. the card link works and follows the template,
2. at least one profile listed in it links back to the card, and
3. the person asking is the person listed (a PR from the GitHub account in the card, or a message from the PA email or a profile in the card).

The `link_back_checked` date records when we last checked step 2.

## Rules

- Use a dedicated address for `pa_email`, not your personal inbox. It will be public.
- Say what you're open to. Vague entries ("open to anything") aren't listed.
- No ads, no recruiting, no affiliate links.
- Want out? Open a PR deleting your file, or use the contact form. We remove entries within a few days.
- Entries whose card stops working, or whose profiles stop linking back, are removed.

The directory doesn't rank, score or vouch for anyone.
