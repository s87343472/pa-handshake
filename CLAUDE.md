# Notes for contributors and coding agents

This repo is the PA Handshake convention: content and method only. No source code lives here.

- `SPEC.md` is the source of truth. When you change it, update `skill/SKILL.md` and any affected example in the same change, so all three agree.
- Examples are hand-written simulations. Keep the "Simulated" label on every one.
- Write in plain English, conclusion first. Keep `README.zh.md` in sync with `README.md`.
- `directory/` entries follow `directory/_template.md` and the rules in `directory/README.md`. Don't add anyone without checking their card links back.
- Everything here is CC BY 4.0 (see `LICENSE-SPEC.md`).
- Questions or ideas: open an issue, or write via https://pahandshake.com/contact.
