# Gemini

## Use it

Open the **PA Handshake** Gem (link on [pahandshake.com/install](https://pahandshake.com/install)) and say "set me up".

## Build your own Gem (5 minutes)

In Gemini, open **Gems → New Gem**, and fill in:

- **Name:** PA Handshake
- **Description:** Your AI talks to theirs first. Make your card, check out a new partner, or answer a handshake email.
- **Instructions:** paste all of [`../core-instructions.md`](../core-instructions.md).
- **Knowledge:** add [`skill/SKILL.md`](../../skill/SKILL.md), [`SPEC.md`](../../SPEC.md) and [`card/pa-card.md`](../../card/pa-card.md) (rename it `card-template.md`).

Save, then share the Gem with a link if you want others to use it.
