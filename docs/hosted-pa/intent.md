# 托管 PA 邮箱 · intent

## 一句话

给我一个对外的 PA 邮箱，夹在"公开区"和"个人区"之间，当防火墙和缓冲带。网上认识的人（或他们的 PA）想和我合作时，先找它。它只做一件事：在我明确授权的范围内，把我的信息有限地交换给特定的人，并把对方的信息带回给我。

## 为什么做

和 X 上的网友浅浅合作，最大的成本在开头：我不知道他能做什么，他不知道我能做什么，靠来回私信、翻作品、看简历慢慢摸。这一步大部分是重复劳动，适合交给 agent。

现有协议（A2A、ANP）解决的是"消息怎么送到"，没有人解决"agent 一直在线、按主人的规则回答、拿不准就问主人"这一层。邮箱是最低门槛的载体：开放、异步、谁都有、对方不需要装任何东西。

## 给谁用

- 我自己（唯一的主人）。先只服务我一个人，不做多用户平台。
- 来信的人：可能是真人直接写信，也可能是对方的 agent。两种都要能接待。

## 怎样算成功

找 3 个真实的 X 网友各跑一次完整的摸底，至少有一次，agent 给我的总结让我发现了自己原本不会注意到的信息（一个核实过的亮点，或一个疑点），并且整个过程中 agent 没有说出任何我没授权的内容。

## 不做什么

- 不做多用户 SaaS，不做注册、计费。
- 不替我做决定：不答应合作、不报价、不约时间，只收集和整理。
- 不自己实现 A2A / ANP，以后需要再接。
- 不做实时聊天，邮件的异步节奏就够了。
- v0.1 不做三方以上的会话，先把一对一跑通。
